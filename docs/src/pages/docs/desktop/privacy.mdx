# Privacy

GChat does not send product analytics or automatic crash reports. Diagnostic logs,
chat history, saved memories and performance measurements remain in your configured
application data directory unless you explicitly share them or configure a service
that processes them.

Using a remote model or LAN host sends requests to that selected host. Enabled
tools and coding integrations can access their configured services and permitted
files. Model downloads and update checks contact their configured distribution
servers. Those operations are not analytics and are not disabled by this policy.

Inspect logs before sharing them: local diagnostics may include paths, errors or
request details. GChat does not upload those logs automatically.
